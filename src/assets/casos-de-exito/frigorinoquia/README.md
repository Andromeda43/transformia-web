# Assets — Frigorinoquia

Poné acá las imágenes reales del proyecto. Van a pasar por `astro:assets` (optimización automática: WebP/AVIF, tamaños responsive), así que cualquier formato de origen (PNG, JPG) sirve — no hace falta comprimir a mano antes.

Nombrá los archivos así para que sea fácil referenciarlos al armar la página:

- `screenshot-apertura.png` — captura de `app_apertura`
- `screenshot-presa.png` — captura de `app_presa`
- `screenshot-granel.png` — captura de `app_granel`
- `screenshot-despacho.png` — captura de `app_despacho`
- `screenshot-reportes.png` — captura de `app_reportes`
- `screenshot-cobranza.png` — captura de `app_cobranza`
- `foto-etiqueta-zpl.jpg` — foto de una etiqueta impresa real
- `foto-guia-despacho.jpg` — foto o export de una guía de despacho
- `foto-reporte-produccion.jpg` — foto o export de un reporte

No hace falta que estén las 9 — con las que tengas arrancamos. Si el nombre no coincide exactamente no pasa nada, lo ajusto al armar la página.
